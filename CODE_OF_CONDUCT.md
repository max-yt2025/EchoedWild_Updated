# EchoedWild Code of Conduct

## 🌎 Our Commitment

EchoedWild is committed to providing a welcoming, respectful, and collaborative environment for everyone who contributes to the project.

We want EchoedWild to be a place where developers, testers, researchers, designers, writers, and beginners can work together to build something meaningful.

By participating in the EchoedWild project, you agree to follow this Code of Conduct.

## 🤝 Expected Behavior

Contributors and team members are expected to:

* Treat others with respect and professionalism.
* Welcome contributors of different experience levels.
* Give constructive feedback.
* Be open to different ideas and approaches.
* Communicate clearly and respectfully.
* Give credit to other contributors when appropriate.
* Respect project decisions made by maintainers.
* Help create a positive and productive development environment.

You do not need to agree with every idea or decision. Disagreements should be handled respectfully and focused on the project rather than the person.

## 🚫 Unacceptable Behavior

The following behavior is not acceptable within the EchoedWild community:

* Harassment, bullying, or intimidation.
* Discrimination or hateful behavior.
* Personal attacks or repeated insults.
* Deliberately disrupting project discussions or development.
* Spam, trolling, or intentionally misleading contributions.
* Sharing another person's private information without permission.
* Threatening or encouraging harm toward others.
* Malicious code or intentionally harmful changes.
* Attempting to access systems, accounts, or information without authorization.
* Misusing access provided through the EchoedWild project.
* Repeatedly ignoring project, security, or contribution guidelines.

## 🔐 Security & Privacy

EchoedWild contributors must respect the security and privacy of the project and its contributors.

Never share or request another contributor's:

* Passwords
* Authentication codes
* API keys
* Access tokens
* Private keys
* Cloudflare credentials
* Resend API keys
* Supabase service-role keys
* Other confidential credentials

If you discover a security vulnerability, follow the instructions in [`SECURITY.md`](SECURITY.md) rather than publicly exposing the vulnerability.

## 👥 Developer & Tester Team

Members of the official **EchoedWild Developer & Tester Team** may receive additional GitHub access for collaboration.

Additional access comes with additional responsibility.

Team members must:

* Use project access only for authorized purposes.
* Keep private project information confidential when requested.
* Never share organization invitations or permissions with unauthorized people.
* Never use another person's GitHub account.
* Never attempt to access repositories, systems, or services they were not authorized to access.
* Report accidental access or security issues to the maintainers.

GitHub organization or team access may be removed if it is misused or if project guidelines are repeatedly violated.

## 🧑‍💻 Pull Requests & Code Reviews

Code reviews should focus on improving the project.

When reviewing someone's work:

* Explain problems clearly.
* Suggest improvements when possible.
* Avoid personal attacks.
* Respect that contributors have different experience levels.
* Give feedback about the code or contribution, not the person.

Likewise, contributors should be open to reasonable feedback on their work.

## 🌱 Beginners Are Welcome

You don't have to be an experienced developer to contribute to EchoedWild.

First-time contributors are encouraged to ask questions, work on beginner-friendly issues, test features, improve documentation, and learn from other contributors.

Mistakes are part of learning. What matters is communicating honestly and making a reasonable effort to improve.

## 📢 Reporting Concerns

If you experience or witness behavior that violates this Code of Conduct, please report it to the EchoedWild maintainers.

For general project concerns:

**[contact@echoedwild.com](mailto:contact@echoedwild.com)**

For contributor-related questions:

**[contribute@echoedwild.com](mailto:contribute@echoedwild.com)**

For security vulnerabilities:

**[security@echoedwild.com](mailto:security@echoedwild.com)**

Please do not publicly post sensitive information when reporting a security issue.

## ⚖️ Enforcement

EchoedWild maintainers may take appropriate action when this Code of Conduct is violated.

Possible actions may include:

1. A private or public warning.
2. Removal of inappropriate content.
3. Temporary restriction from project discussions or contributions.
4. Removal from the Developer & Tester Team.
5. Removal of GitHub organization or repository access.
6. Permanent removal from the project in serious or repeated cases.

The response will depend on the severity and circumstances of the violation.
