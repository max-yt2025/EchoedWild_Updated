# 🔐 Security Policy

EchoedWild is committed to providing a safe, reliable, and secure wildlife education platform. We take security issues seriously and appreciate responsible reports from the community.

## 🛡️ Supported Versions

EchoedWild is continuously updated. The **latest production version** is the primary supported version for security fixes.

| Version        | Security Updates                    |
| -------------- | ----------------------------------- |
| Latest         | ✅ Supported                         |
| Older releases | ⚠️ May not receive security updates |

We recommend using the latest available version of EchoedWild whenever possible.

## 🚨 Reporting a Vulnerability

If you discover a potential security vulnerability in EchoedWild, please report it privately rather than publicly disclosing the issue.

### 📧 Email

**Security reports:**
[security@echoedwild.com](mailto:security@echoedwild.com)

Please include:

* A clear description of the vulnerability
* The affected page, feature, or component
* Steps to reproduce the issue, if applicable
* The potential impact
* Screenshots or other helpful information, if safe to provide

**Please do not include passwords, API keys, authentication tokens, or other sensitive credentials in your report.**

## ⏱️ What Happens After a Report?

Our team will review the report and determine whether it represents a legitimate security issue.

If the vulnerability is confirmed, we will:

1. Investigate the issue.
2. Determine its severity and potential impact.
3. Work on an appropriate fix or mitigation.
4. Deploy the fix when ready.
5. Notify the reporter when appropriate.

Response and resolution times may vary depending on the severity and complexity of the issue.

## 🔒 Responsible Disclosure

Please allow EchoedWild reasonable time to investigate and address a vulnerability before publicly disclosing technical details.

We ask security researchers and contributors not to:

* Publicly expose an unpatched vulnerability.
* Access, modify, or delete other users' data.
* Attempt to obtain credentials or private information.
* Perform attacks that could disrupt EchoedWild or its users.
* Use a vulnerability to cause harm.

Security testing should only be performed against systems and resources you are authorized to test.

## ⚠️ Secrets and Credentials

Never commit sensitive credentials to the EchoedWild repository, including:

* API keys
* Authentication tokens
* Passwords
* Private keys
* Cloudflare credentials
* Resend API keys
* Database service-role keys

If a secret is accidentally committed, **do not simply delete it from the latest commit**. The credential should be revoked or rotated immediately.

## 🌱 Thank You

Thank you for helping keep EchoedWild safe, secure, and reliable for students, educators, wildlife enthusiasts, contributors, and everyone who uses the platform.

Responsible security reports help us improve EchoedWild for everyone.
